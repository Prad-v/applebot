Applebot Features User guide Changelog

Features

Appearance

  • Selectable themes under You → Theme (System, Daylight, Midnight, Ocean, Forest, High contrast) with readable text contrast

Health

  • Dedicated Health tab for Apple Health activity, vitals, workouts and clinical records (read-only)
  • Applebot-only medications: enter manually or photograph a label (on-device Vision OCR, confirm before save)
  • Optional daily local medication reminders with a Taken notification action, plus Siri / Shortcuts to mark taken or ask about wellness score
  • Transparent wellness score, 7-day trend, and on-device awareness narrative with a medical disclaimer
  • Ask Applebot from Health opens Chat with a prepared prompt; morning brief can include health lines
  • Never writes medications back to Apple Health

Stocks

  • Dedicated Stocks tab for an on-device watchlist, optional holdings (not broker-synced), and threshold alerts
  • Batch delayed Yahoo Finance quotes, market-session label, and on-device awareness narrative with a not-financial-advice disclaimer
  • Ask Applebot from Stocks opens Chat; confirm-first suggested adds and alerts
  • Morning brief can include markets lines; optional Friday portfolio automation; Siri / Shortcuts for watchlist, quote, and portfolio
  • Best-effort background refresh for alerts (no push server); never executes trades

Scan (3D room)

  • Dedicated Scan tab using Apple RoomPlan (LiDAR Pro) for walk-around room capture
  • Save and share USDZ models; rename / delete on this iPhone
  • Spoken summary of walls, doors, windows, and detected furniture
  • Disabled with a clear warning on iPhone Air / non-LiDAR devices

Surroundings (accessibility)

  • Dedicated Surroundings tab for blind / low-vision scene understanding
  • Camera capture → on-device Vision (labels, OCR, people) → short spoken description
  • Live mode: continuous updates spoken when the scene changes (no repeated taps)
  • LiDAR depth assist when available; warning + continue without it on iPhone Air
  • Assistive only — not for safety-critical navigation; frames stay on this iPhone

Trail / wilderness

  • Dedicated Trail tab for GPS coordinates, waypoints, breadcrumb trail, and compass bearings (works without cell signal)
  • Google Maps–style offline download: pan under a dashed frame, size estimate, detail level, then download OpenTopoMap packs for offline use
  • Weather for “here” via GPS, with a cached forecast when you lose signal
  • Motion sedentary check (pedometer + activity) with per-sensor warnings when hardware is missing
  • AR trail overlay with waypoint bearings; LiDAR depth mesh on Pro — disabled with a warning on iPhone Air
  • Ask Applebot from Trail for where you are, bearing to Car, weather here, map packs, or a sedentary check
  • Location and motion stay on this iPhone; not a certified wilderness navigation instrument

Chat

  • Streaming answers from Apple's on-device language model by default
  • Leaner prompts for document and tool turns, shorter companion replies, and a quiet citation retry when grounded answers miss sources
  • Optional OpenAI or Anthropic backends in Settings (your API key, Keychain only); switch off anytime to return on-device
  • Companion Chat home with search, pinning, swipe-to-delete, and long-press pin/delete
  • Delete the open conversation from the chat ⋯ menu (with confirmation)
  • Copy and share any answer
  • Stop generation at any time
  • Start a brand new conversation any time from inside a chat; every chat is independent
  • Automatic rolling summary so long chats keep working within the model's context window

Memory and personalization

  • Remembers durable facts across chats on this iPhone; review them under You
  • Structured personal profile with confirmed preferences and reply style
  • Behavioral patterns twin card: sleep, exercise, calendar window, interests, stress, spending hints
  • Ranked memory with types, confidence, and expiry for events / open loops
  • Optional morning brief on unlock from Calendar and open loops
  • Document packs UI plus voice notes into a Voice notes pack
  • Write like me style card for on-device rewrites
  • Local intent router that skips RAG and tools when they are not needed
  • Gentle check-ins, family profiles with Face ID, encrypted backup, and local automations
  • Thumbs feedback retunes hybrid retrieval weights on this iPhone

Voice

  • Mic button with on-device speech recognition only
  • Spoken replies and optional hands-free listen-after-speak (voice turns only; typing never opens the mic)

Emotional chat

  • Warm companion by default; also Neutral and Supportive coach
  • Answers “how are you?” in character — never the cold “I don't have feelings” disclaimer
  • On-device mood reading (sadness, anxiety, anger, joy) that adapts tone and reply length
  • When you are clearly upset, Applebot talks with you instead of searching your documents
  • Kind, non-judgmental handling when a request cannot be answered
  • Nothing leaves your iPhone: mood reading runs locally

Connectors

  • Calendar: ask about your schedule and add events. Stays on your iPhone
  • Reminders: list to-dos, add reminders, mark them done after approval. Stays on your iPhone
  • Apple Health: ask about steps, sleep, heart rate, workouts and clinical health records. Read-only; stays on your iPhone
  • Gmail: search and read your email, and save reply drafts. Applebot never sends email
  • Weather: current conditions and a short forecast via Open-Meteo (no account)
  • Stocks: latest prices for tickers, indices and crypto via Yahoo Finance (no account)
  • Web search: titles and snippets via Brave Search (your own API key)
  • Approval for every change: the exact draft or event is shown first, and nothing happens unless you approve
  • Off until you switch them on; pause any connector without signing out
  • Replies show which connector was used
  • Secure sign-in (PKCE) in a system sheet, tokens in the Keychain, email and web snippets treated as untrusted

Private documents (RAG)

  • Import PDF, text, Markdown, RTF, CSV, JSON, YAML, and images; or paste text
  • On-device OCR for scanned PDFs and photos of documents
  • Hybrid retrieval: semantic vectors plus BM25 keywords, fused and de-duplicated
  • Answers with citations like [1], and a "Why this answer?" view of the search query and passages
  • Honest "not found in your documents" answers instead of guesses
  • Attach documents to a chat with the + button: Files, Photos, pasted text, or your library
  • Per-chat search scope: all documents or the attached subset, shown as removable chips
  • Duplicate detection when re-importing the same content

Privacy and security

  • No Applebot servers, accounts, or analytics. No network requests unless you switch on a connector or an external model, each of which talks only to its own service
  • Chats and documents stored in a file-protected folder, encrypted at rest
  • Optional Face ID / passcode lock whenever the app goes to the background
  • Originals are not copied; only extracted text and search vectors are stored
  • Delete all chats and documents in one tap, which also signs out of connected accounts

Quality

  • Retrieval quality measured with recall@k and MRR, gated in CI
  • Automatic recovery from context-window overflow
  • Clear status when Apple Intelligence is unavailable, and how to fix it

Coming later
